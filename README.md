# Game of Numbers

A console game about numbers and resource management. Made in my free time.

> Note: this is an old project written it in 2024.

## Tutorial

You are given two numbers: your number and a target number. Your goal is to make your number into the target number.

You can use the four basic math symbols.

The twist of the game is that your resources are limited. You can use each number only three times, along with three + signs, three - signs, one /, and one *.

### Getting more resources

- Defeat a target number to earn score, a few random digits and symbols.
- After every kill you enter the shop, which offers 3 random items:
  - digits cost **200 score** each
  - symbols cost **500 score** each

## Tips

- There are no zeros in this game, remember it.
- Every few kills you fight a boss, which is just a higher target number.
- Using * and / is a bit more challenging, but you can earn extra points by choosing them.
- You can leave the game by typing `Exit`

## Goal

Your main goal is to get 100 000 points. It is not easy, though, so you'll need to put in some effort to reach it.

## How to play

1. You need to have installed python.
2. Download `main.py`.
3. Install the libraries:

   ``
   pip install termcolor
   ``

4. Then you can run this game in terminal by typing:

   ``
   python main.py
   ``
